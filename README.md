# roblox-scanner
This is a project for ODBIT. Go to https://odbit.org/ for more information.
--------------------------------------------------------------------------------------------
Roblox Scanner is a open source project using Python to scan through ROBLOX user ID's and detecting if they
have a match of words on a json file that will be in the project.
This is open source, but please credit officialODBIT, or ODBIT's founder if you do use this open source
project. Or, you can add a link to the GitHub resp..
If you are caught using this open source project without crediting in any way, you will be
sent a cease and desist.
